ROYAL IVORY & GOLD HINDU WEDDING INVITATION
===========================================

Open index.html in a modern browser to preview the invitation. An internet connection is used for web fonts; the layout itself is contained in index.html.

CURRENT DESIGN
- Interactive envelope opening cover
- Royal ivory, gold and maroon Hindu wedding-inspired styling
- Couple names section and reserved area for the real couple photograph
- Chronological, text-only event cards for 2 and 3 December 2026
- Special visual highlight for Hastmelap
- Countdown to Hastmelap
- Dedicated venue section with Google Maps link
- Optional user-activated music control
- Gentle floral effects and responsive mobile layout
- No RSVP, WhatsApp RSVP, or guest response form

IMPORTANT: EVENT DETAILS ARE STILL PROVISIONAL
Before publishing, verify the dates, times, event names, venue/address, couple names, family names and any ceremony descriptions. Replace the couple photo placeholder with the real photo when available. Do not share the website publicly until all details are checked.

PERSONALISING THE WEBSITE
1. Open index.html in a text editor.
2. Search for "Bride’s Name" and "Groom’s Name" and replace them with the correct names.
3. Replace the venue name/address in the Venue section.
4. In the script, set MAPS_QUERY to the verified venue name and address, for example: "Venue Name, Full Address, City, India".
5. To add optional music, set MUSIC_URL to a direct MP3 URL you have permission to use. Music will only play after a visitor taps the music button.
6. Replace the reserved photo placeholder with the couple's actual photograph when supplied.
